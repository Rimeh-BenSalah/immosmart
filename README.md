# ImmoSmart

Plateforme web d'annonces immobilières (projet de fin de module DevOps, ISET).

## Architecture

- Front-end : Angular (port 4200)
- Back-end : Spring Boot 3.5, Java 17, Maven (port 8081)
- Base de données : MySQL

## Démarrage

À compléter : la commande de démarrage sera `docker compose up -d` une fois Docker Compose en place.
